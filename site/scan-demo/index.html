The scan, replayed

Under the hood: agents decide, code checks

A language model is good at judgement: is this notice describing a laundering method, and which known pattern does it resemble? It is not trusted with anything that can be checked mechanically. So the scan alternates: an agent makes a call, ordinary deterministic code verifies it, and only then does the next step run.

Agent: a Claude model making a judgementCode: deterministic, same input same answerPerson: the owner's decision, recorded
Tools through MCP, not open access

The agents reach the outside world only through two Model Context Protocol servers written for this job. Every write-capable call passes a permission check in code before it runs.

After a person decides: two paths

The scan never creates a typology. A person's decision on each link sends it one of two ways: a link to a typology NEXUS already governs goes to that typology's desk; a pattern that matches nothing can become a new typology, and once live it is one the next advisory links to directly.
